--- Array / Sorting / Search ---

	- Find the immediate next greater number of a given number (cannot repeat digits)
		Input: 123  → Output: 132
		Input: 21   → Output: -1
		Input: 1239876 → Output: ? (Infosys)

	- Sort array of characters — Dutch National Flag variant
		Input:  ['b','b','c','a','b','c','b','b','a']
		Output: ['a','a','b','b','b','b','b','c','c']
		Space: O(1), Time: O(N) (Algosec, JPMC)

	- Dutch National Flag — sort array of 0s, 1s, 2s
		int[] arr = {0,0,1,0,1,2,1,1} (JPMC)

	- Find minimum element in a rotated sorted array (unique elements, rotated at least once)
		[3,4,5,1,2] → 1 | [4,5,6,7,0,1,2] → 0 | [11,13,15,17] → 11 (ZeMoSo Labs — Round 2)

	- Find closest element to target in sorted array
		arr = {2,5,6,7,8,8,9}, target = 4 → 5
		arr = {2,3,15,13,18}, target = 12 → 12
		arr = {1,2,3,4,15,18}, target = 11 → 15 (ZeMoSo Labs)

	- Two Sum problem
		nums = [50, 75, 100, 125], target = 175 → return [1, 2] (EG Healthcare)

	- Calculate minimum difference pairs from a list and print in ascending order
		List = {6,4,2,10} → (2,4), (4,6) (NPCI)

	- Spiral Matrix (Asimily)

	- Bulls and Cows — https://leetcode.com/problems/bulls-and-cows/ (Asimily)

	- Check if a given string of brackets is balanced or not (Dell)
	- Longest valid (well-formed) parentheses substring
		"(()" → 2 | ")()())" → 4 (ZeMoSo Labs — Round 2)

		"bcabc" → "abc" | "cbacdcbc" → "acdb" (Freecharge)
	- Regular expression matching with '.' and '*'
		s = "aa", p = "a" → false (Thoughtspot)
	- Substring with concatenation of all words (permutation)
		s = "barfoothefoobarman", words = ["foo","bar"] → [0,9] (Thoughtspot)
	- Print the most repeating character of a word in a sentence
